## Why I built it

During the second wave of COVID-19, I found it difficult to get a clear picture of how the situation was changing. I built NearMe Data as a section of NearMe that brought official data into an interface people could explore.

## Working with open data

The application reads published datasets from the Italian Civil Protection repository and presents national and local trends through charts. It uses PHP and JavaScript, with Bootstrap and Chart.js for the interface.

The public dashboard and [C19Sdk](/projects/c19-sdk) are two related ways of working with the pandemic’s open data: one for browsing information, the other for accessing it in Python.

## Current state

I keep the dashboard as part of the project archive. Its data coverage and last update should be checked inside the application; this page does not promise a current monitoring service.
