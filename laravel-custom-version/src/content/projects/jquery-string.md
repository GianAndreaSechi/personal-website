## What it does

JQueryString wraps a few operations I needed when working with query strings: reading a parameter, listing parsed parameters and adding a new value to the current or a new query string.

## The context

It comes from a period when jQuery was part of my everyday web development stack. The repository includes a short example page and usage instructions.

## Current state

The utility depends on jQuery; the README records testing with version 3.6.0. Modern browser APIs offer other ways to handle URL parameters, but I keep this project as a small piece of my development history.
