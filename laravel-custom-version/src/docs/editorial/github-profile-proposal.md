# Gian Andrea Sechi

I’m a Senior Software Engineer at Musixmatch, based in Italy. I’ve worked in software development since 2011, with a focus on backend systems and data.

Outside work, I build tools and experiments that give me a reason to explore an idea. My main open-source project is [irides](https://github.com/GianAndreaSechi/irides), a database introspection tool that makes structured metadata available through APIs, MCP and a web interface. It is in active Alpha.

Other projects include a [Python SDK and MCP integration for OpenF1](https://github.com/GianAndreaSechi/openf1), [a parser for Italian COVID-19 open data](https://github.com/GianAndreaSechi/C19Sdk), and smaller utilities and learning exercises.

I also keep my [school project on the Lorenz system and numerical integration](https://github.com/GianAndreaSechi/tesi-sistemi-dinamici-integrazione-numerica) here. Mathematics, philosophy and psychology are interests I give space to alongside software.

[My website](https://gianandreasechi.com/) brings together the project stories and occasional writing. For career details, see [LinkedIn](https://www.linkedin.com/in/gian-andrea-sechi/).
